        源站访问 账号与网络

        设置网络代理与测试连接 ↗。下面的采集专用地址仅在关闭自定义代理并选择「跟随系统」时使用；选择「直接连接」或启用自定义代理后，以网络代理页为准。

        填写后自动保存，下次打开会恢复；应用本次设置后用于采集。

        尚未载入登录信息

        登录信息默认只保留在本次服务运行的内存中。应用设置后可导出本机加密文件，下次直接导入。E-Hentai 可先尝试不填写 Cookie。

        .ehcred 文件由 Windows DPAPI 加密，只能由这台电脑上的当前 Windows 用户解密。请像密码一样保管，不要发送给他人。

        在 Chrome / Edge 中找到这三项 Cookie
        1. 在浏览器打开你能正常访问的源站作品页。
        2. 按 F12，进入「应用（Application）」→「存储」→「Cookies」，选择当前源站域名。
        3. 找到上面的三个名称，将各自的 Value 填入这里。不要复制整段请求头，也不需要把这些值发到聊天中。

        02 预估与开始

        先应用设置，再验证源站访问。点击“开始采集”查看数量与耗时预估，确认后才开始批量采集。

        验证方式与异常处理说明

        预估只读取本地数据，不访问源站。验证优先从原范围内的缓存、已完成记录随机取样，只检查访问，不改写已有数据；无缓存样本时随机检查待处理作品。每次最多尝试 3 条，正式采集仍按原队列进行。不可用提示后再次验证会临时换其他候选；若浏览器也打不开，可点击“确认不可访问并跳过”，继续原任务时不再请求这条。暂缓验证本身不记录失败；正式批量采集会自动记录不可用作品并继续队列。登录、浏览器验证和限流仍会停止请求；处理后可点击“重新验证失败作品”。批量采集须在预估后单独确认。
